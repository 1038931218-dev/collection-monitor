# 🏢 润锋 AI 商业团队 · 组织与会议机制

**生效日期**：2026-09-29
**适用范围**：Collection Monitor 及后续所有项目

---

## 一、团队角色架构

```
你（润锋）
  ↓ 方向 + 决策 + 最终验收
我（钧辰 · 战略/总顾问）
  ↓ 产品、商业、审计、复盘
Hermes（本地执行层）
  ↓ 编码、测试、修复、部署
各 AI 子角色（按需调用）
  - 开发 AI
  - 审计 AI
  - 白帽攻击 AI
  - 产品 AI
  - 其他专项角色
```

### 角色职责定义

| 角色 | 职责 | 触发条件 |
|------|------|----------|
| 👤 润锋 | 产品方向、关键决策、最终验收、商业判断 | 重大节点、阶段性汇报 |
| 🧠 钧辰 | 战略规划、产品设计、商业分析、审计复核、会议主持 | 全程参与，关键决策把关 |
| ⚙️ Hermes | 编码实现、测试执行、漏洞修复、回归验证、文档存档 | 日常执行层 |
| 🔍 审计 AI | 架构审查、权限检查、数据流审计、安全扫描 | 阶段验收前 |
| 🥷 白帽 AI | 主动攻击、漏洞挖掘、渗透验证 | 安全验收阶段 |
| 👨‍💻 开发 AI | 功能开发、Bug 修复、重构、部署 | 功能迭代阶段 |
| 📈 产品 AI | 市场分析、用户研究、商业模式设计 | 立项与复盘阶段 |

## 二、四层会议机制

### ① 项目会议（Project Meeting）

**频率**：每周或关键里程碑
**参与者**：润锋 + 钧辰 + Hermes

**议程模板**：
```
一、当前状态
二、已完成事项
三、当前问题
四、风险清单
五、下一阶段任务
六、是否需要润锋决策
```

---

### ② 技术会议（Technical Meeting）

**频率**：按技术节点触发
**参与者**：钧辰 + Hermes + 专项 AI 角色

**议程模板**：
```
一、架构设计评审
二、测试覆盖度
三、安全漏洞
四、性能瓶颈
五、技术债务
六、部署准备
```

---

### ③ 产品/商业会议（Product/Business Meeting）

**频率**：每 2 周或关键商业节点
**参与者**：润锋 + 钧辰

**议程模板**：
```
一、用户反馈汇总
二、定位验证状态
三、获客渠道进展
四、转化率数据
五、收费模型测试
六、收入里程碑
七、战略调整建议
```

> **重点**：当项目从"研发阶段"进入"商业验证阶段"后，此类会议频率提升至每周。

---

### ④ 阶段复盘会议（Phase Retrospective）

**频率**：每个阶段结束时
**参与者**：润锋 + 钧辰 + Hermes

**议程模板（最核心）**：
```
一、发生了什么（事实回顾）
二、哪些方法有效
三、哪些方法失败
四、为什么有效/失败（根因分析）
五、应该怎么改（改进措施）
六、哪些可以标准化（SOP 沉淀）
```

**结构化输出模板**：
```markdown

**项目**：
**阶段**：
**会议时间**：
**参与角色**：

### 一、当前状态
-

### 二、完成事项
-

### 三、发现问题
-

### 四、关键决策
-（必须记录：决策内容、决策原因、替代方案）

### 五、待办事项
-（负责人 + 截止时间）

### 六、验收标准
-

-

### 八、经验沉淀
-（以后做类似事情时应该怎么做）

### 九、是否进入下一阶段
- [ ] 是  [ ] 否  [ ] 需要补充工作
```

## 三、核心原则

### 原则一：先跑通，再自动化，再产品化

```
第一轮：人工执行，验证流程
第二轮：半自动化，模板固化
第三轮：全自动化，工具化
第四轮：产品化，对外输出
```

**严禁**跳过第一阶段直接追求自动化。

### 原则二：关键决策必须人工记录

所有"关键决策"必须记录：
- 决策内容
- 决策原因
- 被否决的替代方案

这是团队知识库的核心资产。

### 原则三：经验沉淀 > 功能交付

下一个项目最有价值的不是"我们做了什么功能"，
而是"我们从第一个项目学到了什么"。

### 原则四：商业验证是唯一终极指标

技术完成 ≠ 项目成功。
唯一指标：**第一个陌生用户付费**。

## 四、文档存档规范

### 会议记录存储路径
```
docs/meeting-notes/YYYY-MM-DD-{会议类型}-{项目名}.md
```

```
docs/meeting-notes/2026-09-29-project-collection-monitor.md

docs/meeting-notes/2026-10-10-product-commercial-discussion.md

```

```

```
