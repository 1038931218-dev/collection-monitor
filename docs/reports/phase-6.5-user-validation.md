## 执行策略

### 1. 目标用户画像

**优先寻找**：
- 小型企业主 / 个体户
- 有应收账款管理需求
- 非财务背景（符合产品定位："No finance background needed"）
- 能访问英文网站

**最佳渠道**：
- LinkedIn 中小企业主群体
- 本地华人商会 / 创业社群
- 朋友推荐
- Twitter / 产品社区（Product Hunt, Hacker News）

### 2. 测试流程（最小干预）

```
步骤 1: 发送链接 + 一句话说明
  "这是帮你决定今天该收哪笔钱的工具，试试上传你的发票文件？"

步骤 2: 让用户独立完成
  - 不要主动解释
  - 用户问再答
  - 记录每个步骤的完成时间

步骤 3: 测试后简短访谈
  - "你觉得这个工具能帮你决定今天该收哪笔钱吗？"
  - "哪里让你卡住了？"
  - "你会继续用吗？"
```

### 3. 数据收集原则

**记录**：
- 行为数据（完成每一步的比例）
- 用户原话（不要翻译/美化）
- 卡住的位置
- 时间戳

**不记录**：
- 敏感的财务数据细节
- 用户个人信息（除非用户主动提供）

### 4. 成功标准（第一阶段）

**不强求**：
- 用户数量（1-5 个即可）
- 付费转化
- 功能完整度

**要求**：
- 至少 1 个用户完成完整闭环
- 至少 1 个用户明确表示"有用"
- 收集到真实用户原话
