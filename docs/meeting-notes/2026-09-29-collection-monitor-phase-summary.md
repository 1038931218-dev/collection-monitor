## 一、项目目标与成果

把企业的应收账款 Excel 丢进去，系统告诉老板：**今天最应该收哪几笔钱。**

```
文件上传 → 字段识别 → 数据标准化 → 应收账款计算 → 付款历史分析
→ 优先级计算 → AI分析 → 催收任务 → 催收话术
```

- **确定性数据**（金额、逾期天数、Priority Score）→ 程序计算

## 三、CRITICAL 漏洞复盘

### 漏洞本质
`getById()` 只按 ID 查询，没有绑定 `company_id`，导致跨租户数据泄露。

### 受影响的 Repository
| 文件 | 问题 | 修复方式 |
|------|------|----------|
| `customer.repository.ts` | getById() 未校验 company_id | 加 companyId 参数，跨租户抛 CrossTenantError |
| `invoice.repository.ts` | getById()/update/markPaid() 未传 companyId | 全部绑定 companyId，加 NotFound 守卫 |
| `payment-record.repository.ts` | 无 getById() 方法 | 新增并按 companyId 校验 |

### 正确修法原则
- **不能靠前端权限**（可绕过）
- **不能靠"ID 不容易猜到"**（UUID 可枚举）
- **必须在 Repository 层强制校验**（数据访问最低层）
