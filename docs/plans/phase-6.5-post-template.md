## 操作步骤

1. 打开 https://www.reddit.com/r/smallbusiness/
2. 点击右上角 "Create Post"
3. 粘贴标题和正文
4. 点击 "Post"
5. 记录发帖时间

---

## 追踪指标

发帖后观察 24-48 小时：

| 指标 | 目标 |
|------|------|
| 访问人数 | ≥ 10 |
| 上传人数 | ≥ 2 |
| 报告生成数 | ≥ 1 |
| Priority 查看数 | ≥ 1 |
| Message 生成数 | ≥ 1 |
| 主动反馈数 | ≥ 1 |

---

## 数据收集方式

由于没有后端 Analytics，使用以下方法：

1. **浏览器控制台查看**：
   - F12 → Console → 查看 `[Analytics]` 日志
   - 或打开 localStorage 查看 `collection_monitor_analytics`

2. **手动记录**：
   - 记录每个用户的行为路径
   - 记录用户反馈的原话

3. **评论区回复**：
   - 及时回复评论
   - 引导用户反馈
