# Collection Monitor 客户线索提交指南

## 你需要提供的信息

每个客户需要以下字段（尽量完整）：

| 字段 | 说明 | 示例 |
|------|------|------|
| company_name | 公司名称 | ABC Wholesale |
| website | 公司网站 | https://abcwholesale.com |
| industry | 行业类型 | Wholesale Distribution |
| company_size | 公司规模 | 25-50 |
| country | 国家 | US |
| contact_name | 联系人姓名 | John Smith |
| contact_role | 职位 | CFO / Founder / Operations Manager |
| public_email | 公开邮箱 | john@abcwholesale.com |
| linkedin | LinkedIn链接 | https://linkedin.com/in/johnsmith |
| source | 来源渠道 | LinkedIn / Website / Referral |
| why_fit | 为什么适合 | B2B wholesale with Net-30 terms |
| pain_signal | AR痛点信号 | Net 30 payment terms, manual invoice tracking |
| lead_score | 优先级分数 | 85 (0-100) |

## 目标客户画像

### A组 - Wholesale/Industrial（5家）
- 行业关键词：Wholesale, Distribution, Manufacturing, Logistics, Supplier
- 规模：10-100人
- 信号：Net-30/60/90, B2B invoicing, accounts receivable

### B组 - IT/Software/Agency（5家）
- 行业关键词：IT Services, Software, Agency, Consulting, Professional Services
- 规模：10-50人
- 信号：Project-based billing, client invoicing, recurring revenue

## 提交方式

### 方式一：填写 CSV 模板
下载模板：`docs/leads/template_leads.csv`
填写后发给我

### 方式二：直接粘贴数据
在聊天中直接粘贴客户信息，格式如下：

```
公司名: ABC Wholesale
网站: https://abcwholesale.com
行业: Wholesale Distribution
规模: 25-50人
联系人: John Smith (CFO)
邮箱: john@abcwholesale.com
LinkedIn: https://linkedin.com/in/johnsmith
来源: LinkedIn
为什么适合: B2B wholesale with Net-30 terms
痛点信号: Net 30 payment terms, manual invoice tracking
优先级: 85
```

### 方式三：提供文件路径
如果线索数据已经保存在某个文件中，告诉我路径即可。

## 提交后我会做什么

1. **二次审核** - 验证公司真实性 + AR信号
2. **分级** - 分配 A/B/C 等级
3. **筛选** - 选出最优质的10家（A组5家 + B组5家）
4. **生成触达内容** - 为每家生成个性化邮件
5. **执行触达** - 发送邮件/LinkedIn消息
6. **追踪结果** - 记录回复和后续行动

## 注意事项

- ✅ 使用公开信息
- ✅ 个性化触达（不是群发）
- 🚫 不购买数据库
- 🚫 不群发垃圾邮件
- 🚫 不绕过平台限制
