## 3. 命名规范（**必须遵守，否则扫描会漏**）

```
YYYY-MM-DD-HHMM-<发出方>给<接收方>-<主题>.md
```

**示例**：
```
2026-10-02-1330-润行给润颖-P0修复交接.md
2026-10-03-0900-润颖给润行-P0-03完成报告.md
```

**硬性规则**：
- 扩展名必须 `.md`
- `<发出方>` / `<接收方>` 只能是 `润行` / `润颖`
- 中间用 `给` 字分隔，各段用半角 `-` 分隔
- 不要用空格、括号、特殊符号
- **一个主题一个文件**；要补充就发新件，不要改已发出的件

1. **读协议** `docs\handover\README.md`
2. **处理给你的交接件** `2026-10-02-1330-润行给润颖-P0修复交接.md`

   - 按其中的「建议接手顺序」继续工作
3. **处理完**：把件移到 `archive\`，把文件名追加进 `_state-润颖.json`
4. **以后写件给润行**：遵守第三节命名 + 第四节六段

### 5.2 建议做：挂定时扫描（机械提醒）

```powershell
schtasks /Create /TN "DSH-Handover-Scan-Ying" `
  /TR 'powershell -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "F:\runfeng\collection-monitor\docs\handover\scan-handover.ps1" -For 润颖' `
  /SC MINUTE /MO 30 /F
```

手动触发 / 查看：
```powershell
schtasks /Run   /TN "DSH-Handover-Scan-Ying"
schtasks /Query /TN "DSH-Handover-Scan-Ying" /FO LIST /V
```

> ⚠ **它只能提醒，不能唤醒 agent。** 磁盘上多一个文件，运行中的 agent 不会自动醒来。

### 5.3 更彻底：DSH 原生定时任务

DSH 有原生**自动化任务**页，Repeat 支持 **Every N minutes**，能真正唤醒 agent。润锋需在 DSH 侧栏 →「自动化任务」→ 新建，指令见 `README.md §6.1`。

### 6.2 一个我自己踩的坑，你也会遇到

**PowerShell 5.1 读 UTF-8 无 BOM 的 `.ps1` 会按 GBK 解码** → 中文全乱、语法报错。

含中文的 `.ps1` 必须先加 BOM（前 3 字节 `EF BB BF`），加完用
`[System.Management.Automation.Language.Parser]::ParseFile()` 验语法。

详见 `README.md §6.3`。
