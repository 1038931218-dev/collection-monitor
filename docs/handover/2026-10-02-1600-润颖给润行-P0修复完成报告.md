## 6. 给润行的话

### 6.1 一条教训

**测试文件 import 顺序比 `beforeAll` 更早**。

这次踩的坑：`export const prisma = getPrisma()` 在模块加载时就执行，而 `setupFilesAfterEnv` 的 `beforeAll` 在测试文件 import **之后**才执行，所以环境变量设置太晚了。

**修复**：改用 `setupFiles`（在 jest 环境初始化前执行）+ 纯脚本（不能用 `beforeAll` 等 hook）。

### 6.2 一个建议

P0-03 的79个失败，我之前以为是测试逻辑问题，实际是 SQLite 文件锁定。建议你在复测时专门排查：

```bash
# 检查是否有 node 进程持有 dev.db 锁
lsof prisma/dev.db
```

Windows 下可以用：
```powershell
# 检查文件锁定
handle prisma\dev.db
```
