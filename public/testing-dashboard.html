如何查看 Analytics 数据

在目标用户的浏览器中：

  1. 按 F12 打开开发者工具
  2. 切换到 Console 标签
  3. 搜索 [Analytics] 查看追踪日志

或查看 LocalStorage：

  1. F12 → Application → Local Storage
  2. 查找键: collection_monitor_analytics
